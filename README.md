Sobre o projeto

Este projeto foi desenvolvido para uma Atividade Extensionista e tem como objetivo criar uma solução simples para ajudar no cadastro e na organização das informações dos idosos.

O sistema foi desenvolvido em Python e possui funções para cadastrar, consultar, listar e excluir informações.

Funcionalidades
Cadastrar idoso;
Listar idosos cadastrados;
Buscar um idoso pelo nome;
Excluir cadastros;
Menu simples para facilitar o uso.
Tecnologia utilizada

Python 3.13

O projeto pode ser executado pelo Visual Studio ou Visual Studio Code.

ODS

O projeto está relacionado ao ODS 03 — Saúde e Bem-Estar, buscando utilizar a tecnologia como uma forma de auxiliar na organização das informações e no atendimento aos idosos.

Objetivo

Aplicar conhecimentos de programação em uma situação prática, criando um sistema simples que possa facilitar a organização dos dados e ajudar no trabalho realizado na instituição.
